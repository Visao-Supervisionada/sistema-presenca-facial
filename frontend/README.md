# Frontend - Sistema de Presença Facial

Frontend em React + Vite + TypeScript para o sistema de presença escolar com reconhecimento facial.

## Tecnologias

- React
- Vite
- TypeScript
- Tailwind CSS
- React Router
- React Webcam

## Como executar com Docker

Crie o arquivo `.env` com base no `.env.example`:

```env
VITE_BACKEND_URL=http://localhost:3000
VITE_FACE_API_URL=http://localhost:8000
